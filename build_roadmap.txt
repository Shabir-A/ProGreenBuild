# Build Roadmap

## Simple workflow
- Build one feature.
- Test it locally.
- Commit it.
- Push it.
- Confirm it on Vercel.
- Move to the next feature.

## Step 0: Foundation
- Repo is on GitHub.
- Vercel is connected.
- The starter page loads.
- Git works locally.
- Copilot or Claude Code is installed and signed in.

## Step 1: Supabase setup
- Create a Supabase project.
- Copy the project URL, anon key, and service role key.
- Add them to `.env.local`.
- Add them to Vercel environment variables.

## Phase 1: Marketing site
- Build the landing page.
- Add portfolio, services, about, and footer.
- Test locally.
- Commit and push.
- Check the Vercel deploy.

## Phase 2: Enquiry funnel
- Add the contact form.
- Add the WhatsApp link.
- Add the email link.
- Create the `enquiries` table.
- Test form submission and email delivery.
- Commit and push.

## Phase 3: Admin dashboard
- Add Supabase Auth login.
- Add the admin enquiries view.
- Add status updates.
- Keep the admin UI plain.
- Protect the route.
- Commit and push.

## Phase 4: Client document access
- Add projects and documents.
- Add project creation and access codes.
- Add document upload.
- Add the public code-entry page.
- Test document access with a valid and invalid code.
- Commit and push.

## Phase 5: Polish
- Check mobile layout.
- Add empty states.
- Add error pages.
- Connect a domain.
- Add analytics if needed.

## Rules
- One feature per commit.
- Test locally before pushing.
- Check the diff before committing.
- Check deployment logs if something breaks.
- Never commit `.env.local`.
