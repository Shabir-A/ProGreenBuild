# Database Schema

- `enquiries`: contact form submissions.
- `projects`: client projects and access codes.
- `documents`: files uploaded for a project.
- `admin_profiles`: optional admin display names.
- `auth.users`: Supabase admin login.

## Key points

- Access codes are long, random, and reusable.
- Public reads for projects and documents should go through server-side code.
- Contact form inserts are public; admin reads and updates are restricted.
- Documents are stored privately and exposed through signed URLs.
