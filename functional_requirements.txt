# Functional Requirements

## Public Site (MVP Complete)
- Landing page with hero section
- Services grid
- Portfolio/gallery showcase
- Testimonials carousel
- About section
- Contact information (phone, email, social links)
- Contact form for enquiries (NEW)

## Admin Dashboard

### Authentication
- Email + password login at /admin/login
- Supabase Auth integration
- Session management and logout
- Protected admin routes with middleware
- Secure password reset capability

### Gallery Management
- Upload images to gallery (JPG, PNG only, max 5MB)
- Images stored in Supabase Storage
- Display and manage gallery items
- Delete gallery images
- Reorder gallery items (display_order)
- Public gallery pulls from database (not hardcoded)

### Email Configuration
- View current enquiry email address
- Change email address that receives contact form submissions
- Settings stored in Supabase database
- Only logged-in admins can modify

### Contact Form Handling
- Simple contact form on public site (Name, Email, Message)
- Form submission sends email to configured admin email
- Email delivery via SendGrid or Resend
- Success/error notifications to user
- No authentication needed for users

## What Admin CANNOT Do
- Upload sensitive documents (prices, addresses, contracts)
- Edit service descriptions or pricing
- Modify testimonials
- Access user data or analytics
- Manage client projects or documents
- Change site design/layout

## Non-functional Requirements
- Mobile responsive design (3 breakpoints: mobile, tablet, desktop)
- Fast page load performance
- Minimal, intuitive admin UI
- Environment variables for secrets (API keys, Supabase URLs)
- File upload validation (type + size)
- Input sanitization for form submissions
- Rate limiting on API endpoints
