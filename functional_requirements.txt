# Functional Requirements

## Public Site
- Render homepage content from Supabase on each request
- Show hero, services, process stages, gallery, testimonials, about, and contact sections
- Show social media links when configured, otherwise show a fallback state
- Open an enquiry modal from the contact section
- Accept public enquiry submissions with name, email, enquiry type, and optional message
- Send each enquiry to the configured receiving email through Resend
- Log each enquiry into the `enquiries` table
- Show privacy policy at `/privacy`
- Show terms and conditions at `/terms`

## Admin Dashboard

### Authentication
- Require Supabase-authenticated access for `/admin`
- Support email/password sign-in
- Support logout
- Refresh auth session for admin traffic through middleware

### Content Management
- Upload gallery images to Supabase Storage
- Save gallery captions in the database
- Delete gallery images and their associated records
- Upload a site logo
- Upload one image per renovation process stage
- Add testimonials
- Delete testimonials
- Add social media links
- Delete social media links
- Update the WhatsApp/contact number stored in `site_settings`

### Enquiry Management
- List enquiries in the admin dashboard
- Separate enquiries into open and archive views based on status
- Update enquiry status between `pending_reply`, `awaiting_customer`, `converted`, and `closed`
- Delete enquiries

## Constraints
- Allow only JPG and PNG uploads
- Reject uploads above 5MB
- Validate email format server-side
- Apply a best-effort rate limit on the enquiry endpoint
- Store secrets in environment variables
- Keep the public site mobile responsive
